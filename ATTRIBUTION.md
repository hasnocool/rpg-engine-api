# Attribution and content licensing

The engine source code is intended to be distributed under the repository's declared MIT license metadata.

Content packs are separately licensed artifacts. Every published content definition must retain source/license metadata. The engine must not treat publicly readable game material as redistributable content merely because it can be viewed online.

The planned SRD-compatible content package must include the attribution required by its source license (including CC BY attribution where applicable) in the package manifest and release materials. Custom content authors remain responsible for supplying accurate license/source metadata.

Trusted extensions are deployment-controlled executable software and are not content packs. Their license and provenance must be reviewed independently before deployment.
